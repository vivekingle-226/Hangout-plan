# 💌 A Little Question

A small, interactive hangout invitation website where your friend can choose a **date, place, and food**, and then confirm the plan.

The selected response is stored securely in **Supabase** so the invitation creator can view the submitted plan.

---

## ✨ Features

- 📅 Choose a date
- 📍 Choose a hangout place
- 🍕 Choose food
- 💬 Interactive invitation interface
- 💾 Save responses using Supabase
- 📱 Responsive design
- 🌐 Can be deployed as a public website

---

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Supabase
